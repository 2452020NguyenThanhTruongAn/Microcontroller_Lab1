## 🚀 How to Run Simulation
1. Open the `.ioc` project file in **STM32CubeIDE** and build the project (`Ctrl + B`) to generate the `.hex` file.
2. Open the `.pdsprj` file in **Proteus** (Run as Administrator).
3. Double-click the **STM32F103C6** component, select the generated `.hex` file path, and press **Play**.
